# 精简版交付验收清单

用途：新装或代搭建完成后，按序勾选。机器能查的项先跑自动脚本，浏览器项人工勾。

```bash
# 在安装根目录执行（把域名换成实际值）
cd /www/wwwroot/multisig-station-streamline
SITE_DOMAIN='你的域名.com' bash deploy/accept-streamline.sh
```

通过标准：**自动项全部 PASS**，且下方「人工项」全部勾选。任一项 FAIL 先修再交付。

---

## A. 一键安装

| # | 检查项 | 期望 | □ |
|---|--------|------|---|
| A1 | 安装脚本跑完无报错退出 | 终端出现「安装完成」与 API 端口 | □ |
| A2 | 记下 API 端口 | 常见 `8791`（以脚本输出为准，勿猜） | □ |
| A3 | PM2 进程存在 | `pm2 list` 有 `multisig-streamline-api`（或 `.env` 里 `PM2_NAME`）且 online | □ |
| A4 | 本机健康检查 | `curl -s http://127.0.0.1:<PORT>/api/health` 含 `"ok":true` 与 `"edition":"streamline"` | □ |
| A5 | 前端产物 | 存在 `frontend/dist/index.html` | □ |
| A6 | 配置落盘 | `backend/.env` 含 `PORT`、`INSTALL_ROOT`、`PM2_NAME`、`UPDATE_RELEASES_URL`、`JWT_SECRET` | □ |
| A7 | 未误用总部端口 | health 不是 `"edition":"hq"`；反代不要指到 `8788` | □ |

自动脚本覆盖：A3–A7。

## B. Nginx 反代 + 伪静态

| # | 检查项 | 期望 | □ |
|---|--------|------|---|
| B1 | 网站目录 | 宝塔站点根 = `…/frontend/dist`（不是仓库根目录） | □ |
| B2 | HTTPS | 证书有效，强制 HTTPS 已开 | □ |
| B3 | `/api` 反代 | 代理目录 `/api`，目标 `http://127.0.0.1:<PORT>`，**末尾无 `/`** | □ |
| B4 | 仅一份 `/api` | 不要重复添加反向代理 | □ |
| B5 | SPA 伪静态 | `try_files $uri $uri/ /index.html;` | □ |
| B6 | 一键修配置（可选） | `DOMAIN=域名 API_PORT=端口 bash deploy/fix-baota-nginx.sh` 后 `nginx -t` 通过 | □ |

公网验证（把域名换成实际值）：

```bash
curl -sS "https://你的域名.com/api/health"
# 必须含 "edition":"streamline"

curl -sI "https://你的域名.com/login" | head -n 1
# 期望 200（不要 404）

curl -sI "https://你的域名.com/branch/presets" | head -n 1
# 期望 200（SPA 回退到 index.html，不要 nginx 404）
```

## F. 第一次出码（业务闭环）

站长路径（必做）：

| # | 检查项 | 期望 | □ |
|---|--------|------|---|
| F1 | 站点开通 | `/open` 出现二维码或可复制开通链接 | □ |
| F2 | 签名页可达 | 扫码或打开链接进入 `/o/{会话}`，页面可加载 | □ |
| F3 | 会话未立刻过期 | 打开后短时间内可看到签名引导（默认会话约 5 分钟） | □ |

会员路径（有会员需求时做）：

| # | 检查项 | 期望 | □ |
|---|--------|------|---|
| F4 | 建会员 / 开注册 | 「会员」页按需设注册档；或后台建好会员 | □ |
| F5 | 会员配 2 址 | 会员登录 →「多签地址」保存 2 个地址 | □ |
| F6 | 专属出码 | 打开会员 `/p/u/{码}`，与 `/open` 同页，走该会员地址 | □ |
| F7 | 场景贴码 | 「场景」里至少一张启用卡片，二维码指向正确入口 | □ |

说明：完整链上签名依赖客户钱包与链上手续费，交付验收以 **出码成功 + 签名页可达** 为通过；是否在客户钱包里点签成功，可另记为「链上冒烟」（选做）。

## 失败时优先查

| 现象 | 先查 |
|------|------|
| health 不是 streamline | 反代端口是否指错（尤其勿指 8788 总部） |
| `/login` 404 | 伪静态 / 网站目录是否为 `frontend/dist` |
| 验证码 Not Found | `/api` 目标 URL 是否多了末尾 `/` |
| 能开首页但不能登录 | 无 `/api` 反代，或反代到别的进程 |
| 公网页空白 | `cd frontend && npm run build` |
| PM2 起不来 | `pm2 logs <PM2_NAME>`；确认未与 updater 同名 |

OTA 专项见 [`OTA回归清单.md`](./OTA回归清单.md)。
