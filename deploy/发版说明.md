# 分公司更新包发布说明（总部操作）

发布仓：https://github.com/e12games/multisig-station-branch-releases  
源码仓：本仓库 `multisig-station-branch`

**升级 / 改功能前必读：**

1. [docs/踩坑与决策.md](../docs/踩坑与决策.md)（相关关键词）  
2. [CHANGELOG.md](../CHANGELOG.md)（最近几版）

---

## 〇、发版前检查（必做）

- [ ] 已查阅踩坑手册中与本次改动相关的条目  
- [ ] 已更新根目录 `CHANGELOG.md`（本版本条目）  
- [ ] 若修了生产坑或定了重要约定：已写入 `docs/踩坑与决策.md`（或在 CHANGELOG 注明「无新坑」）  
- [ ] 若改了后台操作方式：已更新 `frontend/src/help/helpContent.ts`，且 `HELP_DOC_VERSION` = 本版 `VERSION`  
- [ ] `VERSION` 文件将改为本版号（打包脚本会写入）

---

## 一、打包

在源码根目录：

```bash
VERSION=20260815 NOTES="修复说明文字" bash deploy/pack-release.sh
```

同日再发一包：

```bash
VERSION=20260815-2 NOTES="热修" bash deploy/pack-release.sh
```

产出在 `dist-release/`：

- `branch-VERSION.zip`
- `latest.json`
- `PUBLISH.txt`

## 二、上传

1. 在 releases 仓创建 **Release**，Tag = 版本号（如 `20260815`），上传 zip 附件  
2. 把 `latest.json` 提交到 releases 仓 **main** 根目录（覆盖旧文件）

## 三、分公司侧

后台登录（超级管理员）→ **系统更新** → 检查更新 → 立即更新  

失败会自动回滚；`.env` 与数据库不会被覆盖。备份保留最近 2 份。
