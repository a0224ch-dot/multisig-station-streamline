# 场景对接说明（分公司入口 `/p/{slug}`）

给场景开发者、交易所 H5、分公司技术看。  
收费名额等能力另议；本文只讲 **怎么接到多签入口**。

## 原则

1. **场景只配置入口 URL**（HTTPS），不要写死 TronLink/OKX 等深链。  
2. 入口是长期落地页：`https://你的分公司域名/p/exchange`（路径可在「公网页装修」改）。  
3. 真正开通是短时会话：用户在落地页点「开始开通」后才进入 `/o/{token}`。  
4. 钱包深链由多签站开通页处理；场景侧只需打开入口 URL。

## 最小对接

### 1）跳转开通

```text
https://分公司域名/p/exchange?ref=订单号或用户ID
```

可选回跳（须先在分公司后台「对接」配置域名白名单）：

```text
https://分公司域名/p/exchange?ref=ORDER123&returnUrl=https://你的场景域名/done
```

`returnUrl` 回跳时会带上大致参数：

- `status=ok|fail`
- `address`（成功时）
- `txId`（成功时）
- `ref`（若开通时传了）
- `error`（失败时）

### 2）用开源模板

仓库/目录：`examples/multisig-scene-starter`（亦可单独建成开源仓发布）

1. 复制模板  
2. 改 `config.js` 里的 `entryUrl` 为分公司入口  
3. 本地用任意静态服务器打开，或部署到自己的域名  
4. 点「去开通多签」验证闭环  

模板可免费发布到网上；用户把入口改成自己分公司的链接即可商用对接。

### 3）进阶（App / 服务端）

分公司后台「对接」创建 API 密钥后：

```http
POST /api/partner/v1/open/session
X-Api-Key: msk_…
{ "returnUrl": "https://场景/done", "ref": "ORDER123" }
```

把返回的 `openUrl` 放进 WebView。详见后台「对接」页。

## 不要做的事

- 不要把会过期的 `/o/xxxx` 当成永久模块链接发给场景。  
- 不要在开源场景里写死某一家钱包的 scheme 当唯一入口。  
- 不要期望开源包内「强制付费」防得住篡改；收费应做在分公司开通权限侧（后续）。
