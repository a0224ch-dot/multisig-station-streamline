# Multisig Scene Starter（多签场景最小模板）

免费、可拷贝、可单独发到 GitHub / Gitee。  
用途：演示任意网页如何对接**分公司多签落地页**（`/p/{slug}`）。

## 你只需要改一处

编辑 `config.js`：

```js
entryUrl: "https://你的分公司域名/p/exchange",
```

可选：

- `returnUrl`：开通完跳回哪（须在分公司后台「对接」加域名白名单）
- `refPrefix`：业务单号前缀

## 本地预览

用任意静态服务器打开本目录，例如：

```bash
npx --yes serve .
```

浏览器打开提示的地址，点「去开通多签」。

> 用 `file://` 直接打开也能跳转入口，但回跳 `returnUrl` 在白名单/浏览器限制下可能不理想，建议用 http(s) 本地服务。

## 对接约定（请保持）

1. **只配置入口 URL**，不要在模板里写死 TronLink / OKX 等深链。  
2. 用户打开分公司落地页后点「开始开通」，才会进入短时开通会话。  
3. 收费应在分公司开通权限/套餐侧实现，不要指望本开源包防篡改收费。

更完整说明见分公司多签站仓库：`docs/场景对接说明.md`。
