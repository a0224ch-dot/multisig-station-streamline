# Streamline Partner Scene（精简版友商场景模板）

**免费 MIT** · 可拷贝 · 可单独发到 GitHub / Gitee / 自己的服务器。

给**已用通用注册码注册成功的会员（友商）**：演示如何把业务页接到你的多签开通入口。

## 你只需要改一处

编辑 `config.js`：

```js
entryUrl: "https://你的站点/p/u/你的会员短码",
```

会员短码：登录精简多签站 → **场景** 页顶部可复制专属链接。

可选：

- `refPrefix`：跳转时带 `ref=partner-时间戳`，便于对账（默认 `partner`）

## 本地预览

```bash
npx --yes serve .
```

浏览器打开提示的地址，点「去开通多签」。

> 勿用 `file://` 长期测试；请用 http(s) 本地服务或部署到域名。

## 和后台「友商柜台」的关系

| 方式 | 适合 |
|---|---|
| 后台 **场景 → 友商柜台** | 零代码，直接复制二维码贴柜台 |
| 本模板 | 要把按钮嵌进自己的 H5 / 活动页 / WebView |

两种方式都走 **`/p/u/{会员码}`**，不是站长 `/open`。

## 对接约定

1. **只配置 HTTPS 入口 URL**，不要在本模板写 TronLink / OKX 等深链。  
2. 用户打开入口后会出开通码，再进入钱包签名页 `/o/…`。  
3. **第一版不做 returnUrl 回跳**；开通完成留在多签站成功页即可。  
4. 开通权限、会员天数由精简多签站侧控制，不要指望本模板防篡改收费。
